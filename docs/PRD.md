# AgroTrack — PRD

## Vision
Digitaliser la chaîne de valeur des coopératives agricoles burkinabèses.

## Utilisateurs
- **Gestionnaire coopérative** : saisit les collectes, gère les paiements
- **Agent terrain** : enregistre sur mobile sans connexion
- **Président coopérative** : consulte les bilans

## Priorités Phase 1
1. Registre membres (CRUD)
2. Saisie collectes offline
3. Calcul automatique paiements
4. Export PDF bilan saison

## Métriques succès
- Temps de saisie : < 2 min par collecte
- Fonctionne offline : oui (PWA)
- Adoption : 5 coopératives pilotes en 2026
